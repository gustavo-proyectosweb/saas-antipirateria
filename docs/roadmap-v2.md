# Roadmap Post-Lanzamiento (Versión 2.0)

Este documento contiene las funcionalidades y mejoras de experiencia (UX) pospuestas intencionalmente para ser desarrolladas después del lanzamiento oficial a producción del MVP.

---

## 🚀 Mejoras de UX / Experiencia de Usuario (P1 pospuestos)
- [ ] **Notificaciones en tiempo real:** Avisar a la creadora mediante toast/banner dentro del dashboard cuando entra una nueva compra.
- [ ] **Indicador visual de progreso de subida:** Mostrar barra de porcentaje al subir archivos PDF de gran tamaño (>20MB).

---

## 🔮 Nuevas Funcionalidades (P2 / Out of Scope para MVP)
- [ ] **Personalización de la Marca de Agua:** Permitir a la creadora elegir la posición exacta (esquinas, centro, margen) y opacidad del estampado.
- [ ] **Soporte para archivos .ZIP:** Expandir el motor para permitir empaquetar PDFs estampados junto con otros archivos de recursos digital.
- [ ] **Integración con nuevas pasarelas:** MercadoPago, Hotmart y Gumroad.
- [ ] **Filtros avanzados en el historial:** Buscar compras por rango de fechas o correo del comprador.
